DASH N DINE / IN-GAME GAMEPLAY
01 / Overview

From an idea to a playable world.

Dash N Dine is an independent game development project built in Godot. It explores how a 3D driving environment can connect roads, destinations, and navigation into a cohesive gameplay experience.

This portfolio documents the engineering decisions, technical challenges, player testing, and iterative improvements involved in bringing the project to life.

02 / Engineering

More than a city to drive through.

Creating the environment is only one part of the project. The road network, navigation logic, and gameplay systems must work together to create a functional driving world.

SYSTEM 01

City Environment

Building a 3D urban environment with roads, sidewalks, blocks, and buildings to create a connected world for players to explore.

SYSTEM 02

Road Network

Developing interconnected waypoints to represent available paths through the city and support route selection.

SYSTEM 03

Navigation

Working on destination-based routing so the game can determine paths toward intended locations instead of simply choosing nearby points.

SYSTEM 04

Debugging & Iteration

Testing interconnected systems, investigating unexpected behavior, and refining the implementation as the project develops.
