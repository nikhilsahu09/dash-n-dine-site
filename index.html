The project at a glance

Dine N Dash.

A 3D driving and delivery game built with Godot, combining a navigable city, vehicle selection, and waypoint-based routing into one connected gameplay experience.

Drive. Navigate. Deliver.

Get behind the wheel.
Find your way through the city.

Dine N Dash is an independent 3D driving and delivery game built in Godot. It brings together a custom city environment, vehicle selection, and waypoint-based navigation, with an emphasis on connecting gameplay systems into a cohesive experience.

Explore the game → Explore the engineering

The project runs in the Godot editor. The browser export is still being troubleshot, so a playable web build is not currently available.
