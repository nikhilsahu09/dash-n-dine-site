Dash N Dine.

01 / Overview

Project Overview

From designing a city to connecting the systems that make it navigable, Dash N Dine is an ongoing exploration of game development and iterative problem-solving.

PROJECT FOCUS

Building an interactive world

Creating a 3D environment with connected streets, buildings, and destinations for a driving experience.

DEVELOPMENT APPROACH

Design, test, refine

Developing interconnected systems, testing their behavior, and improving the game through repeated iteration.

02 / Technical Work

Engineering the Game

The game relies on multiple scripts and systems working together, from the 3D environment to road connectivity and destination-based navigation.

SYSTEM 01

City Environment

Building roads, sidewalks, blocks, and structures in a 3D world.

SYSTEM 02

Road Network

Connecting waypoints to represent paths through the city.

SYSTEM 03

Navigation

Developing routing logic to guide players toward intended destinations.

SYSTEM 04

Debugging

Investigating unexpected behavior and refining the systems as development progresses.
