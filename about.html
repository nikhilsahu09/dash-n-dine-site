01 / The Idea

About the Project.

Dash N Dine is an independent 3D driving game project built with Godot. The project brings together environment design, road connectivity, navigation, and iterative testing.

PROJECT OVERVIEW

What I'm Building

The goal is to create an interactive city that players can explore while developing the systems that make the world work.

01 / WORLD DESIGN

A 3D City

Building streets, sidewalks, blocks, and structures to create an environment for driving and exploration.

02 / GAME SYSTEMS

Interactive Navigation

Developing connected waypoints and routing logic to help represent paths through the city toward destinations.

03 / ITERATION

Testing and Refinement

Testing how the environment and navigation behave, identifying problems, and refining the implementation over time.

04 / TECHNOLOGY

Built with Godot

Using Godot and GDScript to develop the 3D environment, gameplay systems, and supporting logic.

An Ongoing Project

Dash N Dine is being developed iteratively. New features and improvements are introduced as systems are tested and refined.
